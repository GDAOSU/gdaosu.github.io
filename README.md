# QinLab Selected Projects

This repository contains the source code for **QinLab Selected Projects**, a lightweight navigation page that highlights key research projects from the OSU Geospatial Data Analytics Laboratory. 

---

## Features

### Modern UI
- Custom dark theme built with CSS variables.
- Radial and linear gradient background for a polished visual style.
- Sticky header with blur and saturation effects.
- Fully responsive grid layout.

### Project Cards
- Uniform image aspect ratio for consistent presentation.
- Alternating layouts for visual balance.
- Metadata badges for conference or dataset information.
- External links to full project pages.

### Accessibility and UX
- Semantic HTML structure.
- Keyboard focus enhancements.
- Smooth scroll functionality.
- Local storage theme preference.

### Structured Data
- Embedded JSON-LD metadata for better previews on search engines and social platforms.

## Adding New Projects

To include more items, duplicate a <article class="card"> block in index.html and update:
- Image URL
- Title
- Badges
- Description
- External links
